# Content Workflow

1. Drop idea in `stores/inbox.md`
2. `npm run new-post -- "topic" --pillar 1`
3. Write 3 drafts into `draft-package.md`
4. Quality check against `voice/`
5. Publish on X (link in first comment, not body)
6. `npm run log -- <slug> --views N --likes N --bookmarks N`
7. After +72h: archive and write one lesson into the main `lessons.md`
